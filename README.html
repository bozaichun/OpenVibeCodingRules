03 / Quick Start

快速开始

把规范拷进业务仓，告诉 AI 按 AGENTS 编码，再按语言加载规则。

STEP 01

复制到业务项目

将 AGENTS.md 与 rules/ 放到项目根目录，保持相对路径。

demo/
├── AGENTS.md
├── rules/
│   ├── AGENTS/ · README/
│   ├── CodeConduct/CodeConduct-Zh-CN.md
│   ├── QualityBaseline/QualityBaseline-Zh-CN.md
│   └── CodingSpec/
│       └── JavaScript&TypeScript/CodingSpec-Zh-CN.md
└── src/
STEP 02

前端引入 WebVariable

不要复制 Token 源码，只在入口按序引入：

ThemeVariable.css
→ SystemVariable.css
→ ProjectReset.css
→ 应用级 CSS

路径： ./rules/CodingSpec/JavaScript&TypeScript/WebVariable/

STEP 03

在 Cursor 中启用

  1. 根目录保留 AGENTS.md（主语言）；其他语言见 AGENTS.*.md / #ovcr-lang
  2. CodeConduct.md 默认 alwaysApply
  3. 按任务 @ 引用语言 CodingSpec
  4. UI 任务再加 DESIGN / WebVariable

向 AI 发起任务时建议写明：请根据 AGENTS.md 进行编码开发；先识别语言与技术栈，再编码。

05 / Quality

质量基线（全语言）

详见 QualityBaseline.md ；各语言 CodingSpec 另有「质量与工程门禁」落点。

1. 代码规范

  • 命名 · 注释 · 格式统一
  • ESLint / Prettier / 阿里 P3C 等按语言启用
  • 提交阶段强制校验
  • 目录分层：控制 / 业务 / 数据 · 公共 · 工具 · 类型 · 配置
  • 接口信封 · 错误码 · HTTP · 幂等 · 版本 · 文档同步

2. 代码质量

  • 高内聚低耦合，三层职责清晰
  • 模块化复用，减少重复
  • 强类型 · 参数校验 · 空值 / 异常边界
  • lockfile + 依赖漏洞扫描
  • 技术债登记，禁止无主临时代码

3. 可维护性

  • 代码可读，关键路径有注释
  • 业务注释保留 puffseed 标识
  • README 写清启动与目录地图
  • 新人可快速上手主路径

06 / WebVariable

前端 Token 全量速览

Token 权威表为 SubjectAuthority.md ，同步产物为 ThemeVariable.css / SystemVariable.css。维护说明见 WebVariable/README.md。

编码规则：字阶 + 行高强制成对

凡使用 --fs-*，必须同步设置权威表中对应的 --lh-*。二者相符相承、缺一不可；禁止只设字阶不设行高，禁止错配。

编码规则：布局尺寸 --layout-*

页头/页脚用于 height / min-height，侧边栏用于 width / min-width，版心用于 width / max-width。禁止当作间距刻度 --size-* 使用。

变量 尺寸 场景
--layout-header 56px 页头高度
--layout-footer 168px 页脚高度
--layout-aside 200px 侧边栏宽度
--layout-content 1200px 版心 
/* ✅ 布局骨架 */
.nav { height: var(--layout-header); }
.aside { width: var(--layout-aside); }
.main { max-width: var(--layout-content); }
.footer { min-height: var(--layout-footer); }

/* ❌ 禁止用 --size-* 冒充页头/版心 */

02

前端再判项目模式

09 / FAQ

常见问题

VariableFile 去哪了？

已更名为 WebVariable，位于 ./rules/CodingSpec/JavaScript&TypeScript/WebVariable/，专用于前端项目变量。

字阶和行高可以只写一个吗？

不可以。使用 --fs-* 时必须同步对应 --lh-*（见 SubjectAuthority §1.4），相符相承、缺一不可。

可以把 WebVariable 复制到 src/styles/ 吗？

不建议。应通过入口 import / <link> 引用，保证 Token 单一维护源。

后端也要 WebVariable 吗？

不需要。后端加载 QualityBaseline 与对应语言 CodingSpec.md 即可。

AI 没有遵守规范怎么办？

显式 @AGENTS.md、@QualityBaseline.md 与对应语言 CodingSpec.md；任务中写明「遵循 OpenVibeCodingRules / puffseed，最小 diff」。
